11. PANDUAN 17 TIPE INPUT KUESIONER & ALUR DATA
====================================================================================================

1. `text`               -> Input isian singkat 1 baris.
2. `textarea`           -> Paragraf teks multibaris.
3. `number`             -> Isian angka saja.

6. `radio_text`         -> Radio button dengan isian teks tambahan pada opsi tertentu.
7. `multiple_choice`    -> Checkbox centang banyak pilihan (+ opsi 'Lainnya').
8. `dropdown`           -> Menu pilihan tarik-turun (<select>).
9. `searchable_select`  -> Dropdown pencarian interaktif (bidang usaha, profesi).
10. `rating_5`          -> Skala linier 1 s/d 5 (Sangat Rendah s/d Sangat Tinggi).
11. `multiple_number`   -> Isian angka majemuk / Take Home Pay dalam ribuan rupiah (.000) & total live.
12. `matrix`            -> Tabel matriks evaluasi skala 1-5 per baris aspek (F21-F27).
13. `matrix_dual`       -> Tabel matriks komparasi dua sisi (F17 Kompetensi vs Kontribusi).
14. `multiple_textbox`  -> Isian teks majemuk per baris aspek.
15. `date`              -> Pemilih tanggal kalender.
16. `time`              -> Pemilih format jam dan menit.
17. `file`              -> Dropzone upload berkas dokumen (PDF, PNG, JPG).
